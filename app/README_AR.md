# 21 Kurd — نسخة Flutter أولية

هذه نسخة أولية لواجهة التطبيق (Prototype)، وليست نسخة جاهزة للنشر.

## المتطلبات
- تثبيت Flutter SDK
- تثبيت Android Studio أو VS Code مع إضافة Flutter
- لتجهيز نسخة iPhone والنشر على App Store: جهاز Mac مع Xcode وحساب Apple Developer مستوفٍ لشروط Apple

## التشغيل
1. فك ضغط الملف.
2. افتح مجلد `21_kurd_flutter_starter` في محرر يدعم Flutter.
3. نفّذ:
   ```bash
   flutter pub get
   flutter run
   ```

## الموجود حالياً
- واجهة رئيسية وهوية ألوان أولية.
- أقسام التاريخ والسياسة والثقافة والفن واللغة.
- تبويبات اكتشف، انشر، المحفوظات، حسابي.
- نموذج تجريبي لإرسال مشاركة.
- اختيار لغة مبدئي واتجاه كتابة بحسب اللغة.

## ما لم يتم تنفيذه بعد
- تسجيل الدخول الحقيقي وإنشاء الحسابات.
- قاعدة بيانات Firebase.
- صلاحيات القارئ والناشر والمدير على الخادم.
- رفع الصور والفيديوهات.
- مراجعة المنشورات والتعليقات فعلياً.
- الترجمة الكاملة إلى السورانية والكرمانجية والإنجليزية والفرنسية.
- لوحة تحكم الإدارة والإشعارات.

## الأمان والخصوصية
لا تضع كلمات مرور أو مفاتيح Firebase أو بيانات حساسة في ملفات التطبيق. يجب فرض صلاحيات النشر والمراجعة بقواعد أمان الخادم، وليس بإخفاء الأزرار داخل الواجهة فقط.
لا تُضمّن بريد الإدارة في الشيفرة العامة؛ اربطه لاحقاً بحساب إداري آمن بعد إعداد Firebase والتحقق من ملكية الحساب.
